# AltoroJ Banking Web Application Risk Assessment

Academic security assessment of the deliberately vulnerable Altoro Mutual banking application.

## Scope

- Controlled black-box assessment of a training application
- Asset classification and business-impact reasoning
- Vulnerability review using scan results and targeted security checks
- Risk prioritization with a probability-versus-impact matrix and CVSS v3.1
- Remediation recommendations for application and infrastructure owners

## Method

1. Identify business-relevant assets and exposed functionality.
2. Review the application surface and collect reproducible evidence.
3. Consolidate vulnerability-scan results with targeted validation.
4. Prioritize findings according to likelihood, impact and exploitability.
5. Document remediation actions, residual risk and assessment limitations.

## Deliverable

A structured assessment report covering the scope, risk matrix, vulnerability prioritization and recommended remediation measures.

## Boundaries

This was an academic lab performed against a deliberately vulnerable training application. It was not a client engagement, and no destructive testing or production access was involved.
